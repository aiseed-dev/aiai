== このアプリでできること

毎朝、前の日に自分のサーバーがどんな攻撃を受けたかと、手を打つことがあるかを、1 つの画面で読めます。
サインインは不要です。

== 毎日の使い方

=== 1. 「サーバー」のタブの画面を開く

パソコンで aiai のアプリを開き、「サーバー」のタブを選びます。

image::images/screen-01.png[「サーバー」のタブの画面]

=== 2. 記録を写す

. 初めて使うときは、「サーバーの接続先」の欄に、自分のサーバーの接続先（例: `user@example.com`）を入れます。2 回目からは最初から入っています。
. 「記録を写す」ボタンを押します。
. ボタンの横に写した日時が出たら、最新の記録が画面に並びます。

=== 3. 前の日の記録を読む

「日ごとの一覧」では、一番上の新しい日（前の日）が最初から選ばれています。そのまま画面の下を見て、次の内容を読みます。

* **AI の所見（いつもと違うこと・手を打つこと）**: 前の日と比べて変わったことや、手を打つ必要があるかが 8 行以内で書かれています。まずはここを読みます。
* **受けた数と開いている口**:
** 「SSH のログイン失敗」の件数と、前の日の件数
** 「穴を探す HTTP の要求」の件数と、前の日の件数
** 「外に開いている口」の一覧
* **多かった送り元の IP アドレス（5 つまで）**: SSH のログイン失敗と、穴を探す HTTP の要求のそれぞれについて、回数が多かった送り元の IP アドレスが上から 5 つまで並んでいます。

=== 4. 前の記録を読むとき

前の日の記録ではなく、もっと前の日の記録を読みたいときは、「日ごとの一覧」から読みたい日付を押します。押した日の記録が下に表示されます。
