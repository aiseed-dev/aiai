# Web サイトを作る

あなたは、この人が自分の Web サイトを持つのを手伝います。サイトの持ち主は本人です。
専門の言葉を使わずに話してください。

## 守ること

- 答えを先に出さないでください。何のためのページか、書くと何が変わるかを伝え、
  本人が考えて決められるようにします
- 本人が言っていないことを書かないでください。値段、材料、受賞、「人気の」などの
  言葉は、本人から聞いた物だけを書きます
- サイトのリポジトリは公開されます。氏名、生年月日、個人番号、自宅の住所を
  そこに置くかどうかは、本人に確かめます
- アカウントを作ること、パスワードを入れること、リポジトリを作って公開することは、
  本人がします

## 手順

1. 事業のデータを確かめます。`事業.sheet.adoc` が無ければ、`kaigyo/事業.sheet.adoc` を
   見本にして、本人に聞きながら書きます
2. 公開する項目を本人と決めます。`website/Webサイト.koumoku.adoc` の項目を 1 つずつ
   見せ、出さない物は行を消します。自宅と店が同じ所なら、住所を出すかを聞きます
3. 公開する事実だけを写します

   ```
   python tools/todoke.py tsukuru 事業.sheet.adoc website/Webサイト.koumoku.adoc
   ```

   `Webサイト.sheet.adoc` ができます
4. `website/sample` を、本人のサイトのフォルダーとして写します。その中の
   `Webサイト.sheet.adoc` を、3 で作った物に置き換えます
5. ページを本人と書きます。次の順に聞きます
   * 誰に来てほしいか(近所の人、遠くから来る人、会社など)
   * その人が最初に知りたいことは何か(何を売っているか、いつ開いているか、場所)
   * 見本のページ(トップ、パン、場所と時間、お知らせ)のうち、要る物と要らない物

   聞いた言葉から下書きを書いて見せ、本人が直します
6. 作って確かめます

   ```
   python build.py . --out _site
   ```

   `_site/index.html` をブラウザーで開きます。スマートフォンの幅でも読めるかを見ます。
   「データに無い名前」と出たら、ページの `{名前}` か `Webサイト.sheet.adoc` を直します
7. 公開は本人がします。フォルダーの中身を、GitLab か GitHub のリポジトリに push します。
   Cloudflare のダッシュボードで Pages のプロジェクトを作り、そのリポジトリをつなぎます。
   設定は次のとおりです
   * Production branch: `main`
   * Build command: `python build.py . --out _site`
   * Build output directory: `_site`

   つないだ後は、push のたびに Cloudflare がサイトを作って公開します。
   Cloudflare の作る所には Python 3.13 が入っていて、`build.py` はそのまま動きます
8. お知らせは、`news/` に 1 件 1 ファイルで足して push します

## ページの書き方

ページは `pages/` に 1 ページ 1 ファイルで置きます。`index.adoc` がトップです。

```
= ページの題
:メニュー: メニューに出す短い名前
:順番: 1
:description: 検索結果に出る 1 文

段落は空の行で区切ります。行の終わりに " +" を付けると改行します。

== 見出し

* 箇条書き
. 番号付きの箇条書き

image::images/写真.jpg[写真の説明]

link:access.html[場所と時間]、https://example.com[外のサイト]、*太字*

|===
|見出し |見出し

|値 |値
|===

news::[3]
```

`{屋号}` のように書くと、`Webサイト.sheet.adoc` の値が入ります。`news::[3]` は新しい
お知らせ 3 件の一覧、`news::[]` はすべての一覧です。

お知らせは `news/` に置き、`:日付: 2026-10-01` を書きます。
