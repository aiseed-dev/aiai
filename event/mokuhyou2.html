目標 2: 問い合わせのフォームの作成

目標 1 の静的なサイトに、問い合わせのフォームを足します。時間内に終わらなくても、このページの順に、後から一人で進められます。

準備

フォームは誰でも送れる口なので、来た物は全部疑い、量を絞ります。それでも集中して送られたら受け口を止めます。最後の守りは認証ですが、今回は作りません。

先に、ダッシュボードで 3 つ足します。

  1. R2 を使い始める: 「Storage & databases」→「R2」→「Overview」で、R2 を足す手続きを最後まで進めます。支払いの方法(カード、PayPal など)の登録を求められます。カードを確かめるために少しの金額が一時的に押さえられることがあり、後で戻ります。毎月の無料の枠(保存 10 GB、Class A の操作 100 万回、Class B の操作 1,000 万回)があり、ふだんの問い合わせの量なら十分にその中に収まります。通らないときは、先に「Billing」の「Payment methods」で支払いの方法を足します
    出典: Cloudflare「Get started」(https://developers.cloudflare.com/r2/get-started/)、「Pricing」(https://developers.cloudflare.com/r2/pricing/)。2026-10-25 に確かめた
  2. Worker の名前: 「Workers & Pages」の「Your subdomain」にあります
  3. トークンの権限: 「API Tokens」で 3 の段のトークンを編集し、「Workers Scripts → Edit」と「Workers R2 Storage → Edit」を足します

R2 にカードなどを登録したくないときは、Google フォームを作ってサイトからリンクする手もあります。その場合、4〜6 の段は要りません。

4. 受け口(Worker と R2)

確かめること: 試験がすべて通る。上げると https://toiawase.〜.workers.dev が出る。

5. 問い合わせのフォーム

初めての flet build web は Flutter SDK を入れるので時間がかかります。入れるかを聞かれたら y です。

確かめること: https://〜.pages.dev/toiawase/ から 1 件送ると「受け付けました」が出る。空のお名前、@ の無いメールアドレス、リンク 3 つは、理由が出て断られる。

6. 担当者のアプリ

確かめること: 利用者マニュアルのとおりに使える。「受け取る」で 5 で送った物が出て、保存先に保存され、もう一度押しても増えない。「HTTP Error 403」なら、「error code: 1010 かもしれません。手引きの User-Agent の所を見て直してください」と頼みます。

7. 通して確かめる

確かめること: 古いサーバーの PHP と管理画面を、公開したままにしていない。

次回の予定

問い合わせの中身は識別情報(お名前、メールアドレスなど)なので、Cloudflare に長く置かず、社内のサーバーに移します。次回は、フォームを受け取る社内のサーバーを Debian で作ります。

質問は、Flet の日本語のチャンネル(Discord)で受け付けます。案内は connpass にあります。
