PHP のサイトを、静的なサイトと Flet のフォームに作り直す

目標 1 は、PHP を使わない静的なサイトを、自分の Cloudflare に公開すること。目標 2 は、問い合わせのフォームを作ることです。コードは Claude が書きます。段ごとのページに、Claude に渡すプロンプトと「確かめること」があります。

考え方の資料: 「既存の Web サイトを静的ファイルにする」(PDF、10 ページ)

事前の準備

  • Python が動く環境
  • Cloudflare のアカウント(無料)
  • Claude のアカウント(無料版でも参加できます。有料版なら Claude Code が使えるので、作業が早く進みます)
  • Google のアカウント(Meet に入るため)

目標 1: 静的なサイトの公開

  1. 手引きを Claude に渡す
  2. 載せる中身を決める
  3. ページを作って、手元で見る
  4. Cloudflare に公開する

デザインを考える(目標 1 の後に)

目標 2: 問い合わせのフォームの作成

時間内に終わらなくても、後から一人で進められます。

目標 2 の準備(R2 を使い始める、トークンの権限)

  1. 受け口(Worker と R2)
  2. 問い合わせのフォーム
  3. 担当者のアプリ
  4. 通して確かめる

Claude への頼み方

  • 見えた物をそのまま伝えます。エラーの文はコピーして貼ります
  • 1 度に 1 つ頼み、そのたびに確かめます
  • 秘密の値(API トークン、STAFF_TOKEN)は貼りません。貼ってしまったら、無効にして作り直します

次回の予定

問い合わせの中身は識別情報(お名前、メールアドレスなど)なので、Cloudflare に長く置かず、社内のサーバーに移します。次回は、フォームを受け取る社内のサーバーを Debian で作ります。

質問は、Flet の日本語のチャンネル(Discord)で受け付けます。案内は connpass にあります。
