PHP のサイトを、静的なサイトと Flet のフォームに作り直す

目標 1 は、PHP を使わない静的なサイトを、自分の Cloudflare に公開すること。目標 2 は、問い合わせのフォームを作ることです。コードは Claude が書きます。上から順に、プロンプトをコピーして Claude に貼り、「確かめること」を見ます。

考え方の資料: 「既存の Web サイトを静的ファイルにする」(PDF、10 ページ)

事前の準備

  • Python が動く環境
  • Cloudflare のアカウント(無料)
  • Claude のアカウント(無料版でも参加できます。有料版なら Claude Code が使えるので、作業が早く進みます)
  • Google のアカウント(Meet に入るため)

0. 手引きを Claude に渡す

  1. 作業のフォルダーを 1 つ作ります(例: static-site)
  2. Claude Code なら、そのフォルダーで開きます。Claude のチャット(claude.ai やアプリ)なら、Claude が示したファイルを自分でこのフォルダーに保存し、コマンドを自分で動かします
  3. 「手引きをコピー」を押して Claude に貼り、続けて下のプロンプトを貼ります

PC が Mac か Linux なら、「Windows」を書き換えます。

1. 載せる中身を決める

中身は Markdown のファイルに書き、Python のプログラム(build.py)がページを作ります。お知らせを足すときは、ファイルを 1 つ足して build.py を動かすだけです。今のサイトがあるかどうかで、プロンプトを選びます。

今のサイトがある場合

Claude がサイトを読めないときは、今のページの文章をコピーして貼ります。

確かめること: トップページの中身が抜けていないか。お知らせのファイルの数が、今の件数と合っているか。古い中身が入っていないか。

新しく作る場合

見本の中身が入っています。自分の会社や店で作るときは、欄の中で書き替えてからコピーします。分からない所は空けたままでかまいません。2 の段まで一度に進みます。

確かめること: 2 の段と同じです。書いたことと違う事実が無いことも見ます。

2. ページを作って、手元で見る

新しく作る場合は、1 の段でここまで進んでいます。

手元で見るのは、python -m http.server 8000 -d public を動かして http://localhost:8000/ です。ファイルをダブルクリックで開くと、リンクが開きません。Claude のチャットで作ったときは、保存した名前の最後が .md、.py になっているかを見ます。

確かめること: トップページ、お知らせの一覧、一つ一つのお知らせが開く(フォームは「準備中」でよい)。パソコンの幅でも、幅を狭くしても崩れない。「お知らせを 1 つ足してください」と頼んで python build.py を動かすと、トップページと一覧に出る。

3. Cloudflare に公開する

ダッシュボード(https://dash.cloudflare.com/)で、自分で 2 つ用意します。

  1. アカウントの ID: 「Workers & Pages」の「Account Details」にあります
  2. API トークン: 右上の人の印 →「My Profile」→「API Tokens」→「Create Token」→ Custom token。権限は「Account → Cloudflare Pages → Edit」の 1 つ。「Continue to summary」→「Create Token」で出ます。1 度しか出ないので、すぐにコピーします。コピーし損ねたら、消して作り直します。Claude のチャットには貼りません
    出典: Cloudflare「Create API token」(https://developers.cloudflare.com/fundamentals/api/get-started/create-token/)。2026-10-25 に確かめた

確かめること: https://(プロジェクトの名前).pages.dev で、手元と同じページが出る。スマートフォンでも開く。cf-publish が最後に出す 8 桁入りの URL は、その回だけの物で、すぐには開けないことがあります。

直したときは、python build.py を動かしてから、同じコマンドでもう一度上げます。

ここまでで、目標 1 を達成です。PHP もデータベースも無い静的なサイトが、自分の Cloudflare から世界に出ました。費用はかかっていません。

デザインを考える

公開できたら、見た目を自分で選びます。Claude に案を出させ、見比べて選びます。

3 つから選ぶか、「1 の色で、2 の看板」のように組み合わせを頼みます。作り直したら、python build.py を動かして手元で見てから、3 の段と同じコマンドで、もう一度上げます。

確かめること: 選んだ案になっていて、パソコンとスマートフォンの両方で崩れていない。

Claude への頼み方

  • 見えた物をそのまま伝えます。エラーの文はコピーして貼ります
  • 1 度に 1 つ頼み、そのたびに確かめます
  • 秘密の値(API トークン、STAFF_TOKEN)は貼りません。貼ってしまったら、無効にして作り直します
