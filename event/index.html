PHP のサイトを、静的なサイトと Flet のフォームに作り直す

今日の目標は、PHP を使わないお知らせのページを、自分の Cloudflare に公開することです。公開できたら、一つの目標を達成です。その先の問い合わせのフォームは、チャレンジです。自分で頑張ります。

コードは Claude が書きます。このページには、Claude に渡すプロンプトと、確かめることを、段ごとに並べてあります。上から順に、プロンプトをコピーして Claude に貼り、確かめていきます。

作る物

目標

  • お知らせのページ(静的な HTML)。Cloudflare Pages に無料で公開します

チャレンジ

  • 問い合わせのフォーム(Flet で作り、flet build web で Web のページにします)
  • 問い合わせの受け口(Cloudflare Worker)。送られた物を確かめ、通った物だけを R2 に置きます
  • 担当者のアプリ(Flet)。R2 から受け取って PC に保存し、R2 から消します

始まる前に

  1. Python の入った PC(Windows、Mac、Linux)と、Claude。無料版でも参加できます。有料版なら Claude Code が使え、Claude がファイルを書き、コマンドを動かすので、早く進みます。無料版では、Claude が示したファイルを自分で保存し、コマンドを自分で動かします
  2. Cloudflare の設定。下の 1〜3 を済ませます

Cloudflare の設定

ここは Claude ではなく、自分でダッシュボード(https://dash.cloudflare.com/)を開いてします。上から順に済ませます。

  1. アカウントを作る。無料のアカウントで足ります
  2. アカウントの ID をコピーする。「Workers & Pages」を開くと、「Account Details」に アカウントの ID があります
    出典: Cloudflare「workers.dev」(https://developers.cloudflare.com/workers/configuration/routing/workers-dev/)、「Find account and zone IDs」(https://developers.cloudflare.com/fundamentals/account/find-account-and-zone-ids/)。2026-10-25 に確かめた
  3. API トークンを作る。右上の人の印 →「My Profile」→「API Tokens」→「Create Token」→ 雛形を使わずに作る(Custom token)。名前を付け、権限に「Account → Cloudflare Pages → Edit」を足します。目標には、この 1 つで足ります。 「Continue to summary」→「Create Token」で、トークンが出ます。
    出典: Cloudflare「Create API token」(https://developers.cloudflare.com/fundamentals/api/get-started/create-token/)。2026-10-25 に確かめた
    トークンは 1 度しか出ません。すぐにコピーし、次の 0 の段で作るファイルに書きます。Claude のチャットには貼りません

止まりやすい所:

  • トークンをコピーする前に画面を閉じた。そのトークンを消して、作り直します
  • トークンに権限が足りない(cf-publish が「権限が無い」と言う)。「API Tokens」でトークンを編集し、権限が入っているかを見ます

0. 手引きを Claude に渡す

最初に、この勉強会の手引き(何を作るか、何を確かめるか、何を決めてあるか)を Claude に渡します。

  • Claude Code なら、下のプロンプトを貼るだけです。手引きは Claude が読みに行きます
  • 無料版なら、先に「手引きをコピー」を押して貼り、続けてプロンプトを貼ります
手引きを開く

PC が Mac か Linux なら、「Windows」を書き換えます。

確かめること: cf-publish --help を打って、使い方の説明が出ること。

確かめること: トークンを書いたファイルが、作業のフォルダーの外(~/.config/cloudflare/)にあること。

1. 載せる中身を決める

今のサイトがあるかどうかで、プロンプトを選びます。

今のサイトがある場合(棚卸し)

サイトの URL を出したくないときは、今のページの文章をコピーして貼ります。無料版の Claude がサイトを読めないときも、同じようにします。

確かめること: 表に、今のサイトにあるページが抜けていないか。フォームで何が来て、誰が受け取っているか。ここは Claude には分からないので、自分で書き足します。

新しく作る場合

今日は見本で試すときは、「架空の会社の見本で進めてください。架空と書いてください」と書きます。

確かめること: 一覧の中身が、自分が答えたことと合っているか。Claude が足した事実が無いか。

2. お知らせのページを作って公開する

確かめること: https://(プロジェクトの名前).pages.dev を開き、ページが出ること。リンクを押して、開かないページが無いこと(フォームはまだ無いので、フォームへのリンクは開かなくてよい)。cf-publish が最後に出す https://(8 桁).(プロジェクトの名前).pages.dev は、その回だけの URL です。上げた直後は開けないことがあります。

見た目を直したいときは、見えたとおりに頼みます。例:「トップの見出しが大きすぎます。半分くらいにしてください」

ここまでで、一つの目標を達成です。PHP もデータベースも無いお知らせのページが、自分の Cloudflare から世界に出ました。費用はかかっていません。

チャレンジ: 問い合わせのフォーム

ここから先は、自分で頑張ります。時間内に終わらなくても、このページの順に、後から一人で進められます。問い合わせのフォームは、誰でも送れる口です。来た物は全部疑い、量を絞ります。何をどう確かめるかは、手引きに書いてあります。

Cloudflare の設定を足す

  1. R2 を使い始める。「Storage & databases」→「R2」→「Overview」を開き、R2 を足す手続き(checkout)を最後まで進めます。この手続きでは、支払いの方法(カード、PayPal など)の登録を求められます。カードを確かめるために、少しの金額が一時的に押さえられることがあります。後で戻ります。問い合わせを置くのに R2 が要るので、ここは越えるしかありません。R2 には毎月の無料の枠(保存 10 GB、Class A の操作 100 万回、Class B の操作 1,000 万回。外への転送は無料)があり、ふだんの問い合わせの量なら、十分にその中に収まります
    出典: Cloudflare「Get started」(https://developers.cloudflare.com/r2/get-started/)、「Pricing」(https://developers.cloudflare.com/r2/pricing/)、「Update billing information」(https://developers.cloudflare.com/billing/get-started/update-billing-info/)。2026-10-25 に確かめた
  2. Worker の URL の名前を見る。「Workers & Pages」の「Your subdomain」に、Worker の URL((名前).workers.dev)に使う名前が出ています。変えるときは「Change」を押します
  3. API トークンに権限を足す。「API Tokens」で目標の段に作ったトークンを編集し、次の 2 つを足します
    • Account → Workers Scripts → Edit
    • Account → Workers R2 Storage → Edit

止まりやすい所: R2 の手続きで支払いの方法が通らない、同じ画面に戻る。先に「Billing」の「Payment methods」の「Add Payment Method」で支払いの方法を足してから、R2 の画面に戻ります。

R2 にカードなどを登録したくないときは、Google フォームを使う手もあります。Google フォームで問い合わせのフォームを作り、お知らせのページからリンクします。Claude には「問い合わせのフォームへのリンクを、Google フォームの https://(フォームの URL)に替えてください」と頼み、Pages にもう一度上げます。この場合、3〜5 の段は要りません。問い合わせは Google に置かれ、Google フォームの画面で受け取ります。

チャレンジ: Google フォームの回答を Flet のアプリで読む。担当者のアプリを Flet で作り、Google Forms API で回答を読むこともできます。前に読んだ時刻より後の回答だけを読めます。そのための準備は、自分で Google Cloud のコンソールでします。

  1. Google Cloud のプロジェクトを作り、Google Forms API を有効にします
  2. 「Google Auth platform」で、同意の画面(Branding)を作ります
  3. 「Clients」で「Create Client」を押し、種類を「Desktop app」にして作ります。出てきた JSON のファイルを保存します

API では回答を消せません(読むことと一覧しかできません)。受け取った回答は、Google フォームの画面で担当者が消します。クライアントの JSON のファイルは秘密の値です。Claude のチャットに貼らず、作業のフォルダーの外に置きます。
出典: Google「Method: forms.responses.list」(https://developers.google.com/workspace/forms/api/reference/rest/v1/forms.responses/list)、「Python quickstart」(https://developers.google.com/workspace/forms/api/quickstart/python)。2026-10-25 に確かめた

3. 受け口(Worker と R2)を作って公開する

確かめること: 試験がすべて通ること。試験の中に、よそのサイトからの送り、空のお名前、長すぎる内容、1 日の上限、鍵の無い担当者の口が入っていること。

確かめること: 上げたときに https://toiawase.〜.workers.dev が出ること。サブドメインが無いと言われたら、ダッシュボードの「Workers & Pages」を開いてから、もう一度上げます。

4. 問い合わせのフォームを作る

初めての flet build web は、Flutter SDK を自動で入れるので時間がかかります。入れるかを聞かれたら、y で答えます。Flutter SDK が入っていれば、書き出しは 1 分ほどです。

確かめること: https://〜.pages.dev/toiawase/ を開き、フォームから 1 件送って「受け付けました」が出ること。

確かめること: お名前を空にする、メールアドレスに @ を入れない、内容にリンクを 3 つ書く。どれも理由が出て、受け付けられないこと。

送れないときは、画面に出た文をそのまま Claude に貼ります。何も出ないときは、ブラウザーの開発者ツール(F12)の「Console」に出た赤い文を貼ります。

5. 担当者のアプリを作る

「受け取れませんでした: HTTP Error 403」と出たら、「error code: 1010 かもしれません。手引きの User-Agent の所を見て直してください」と頼みます。

確かめること: 「受け取る」を押すと、4 で送った物が出ること。受け付けた時刻が日本時間で出ること。~/toiawase/ に保存されていること。もう一度押しても、同じ物が増えないこと(Cloudflare から消えたこと)。

6. 通して確かめる

確かめること: 古いサーバーの PHP と管理画面を、公開したままにしていないこと。ここが動いていると、静的にした意味がありません。

Claude への頼み方

  • 見えた物を、そのまま伝えます。エラーの文はコピーして貼ります。画面は「どこに、何が、どう出たか」を書きます
  • 1 度に 1 つ頼みます。直したい所が 3 つあれば、1 つずつ頼み、そのたびに確かめます
  • 決まっていることを変えたいときは、先にそう言います。例:「フォームに電話番号の欄を足したい。手引きのどこを変えるかから教えて」。手引きを直してから作り直すと、確かめも一緒に直ります
  • 秘密の値は貼りません。API トークンと STAFF_TOKEN は、自分でファイルに書きます。貼ってしまったら、そのトークンを Cloudflare で無効にして作り直します
  • 分からない言葉は、そのまま聞きます。「CORS とは何ですか。いま私がすることはありますか」のように聞けば足ります
