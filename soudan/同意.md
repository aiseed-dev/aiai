# 記録を残すことと、研究に使うことについて

aiai のセカンドオピニオンは、当面、無料の研究サービスとして、募集に応じた人だけに使って
もらいます。使い始める前に、次のことを読んで、同意してください。

- あなたが貼った下書き、AI の答え、あなたが付けた評価、あなたが書いた出来事を、
  あなたの記録として残します
- 記録は、どんな相談をした人がその後どう動いたか、モデルによって答えがどう違うかを調べる
  研究に使います。研究の結果は、数と傾向をまとめた報告書として公開することがあります。
  報告書に、あなたの下書きや出来事の文をそのまま載せることはしません
- 下書きは、あなたが選んだ会社の AI のモデルに送ります。送った中身の扱いは、その会社の
  API の利用規約によります
- 預かるのは、サインインした Apple か Google の ID の番号と、Apple か Google が確かめた
  メールアドレスと、上の記録だけです。名前は預かりません
- 下書きと出来事には、識別情報(氏名、住所、電話、生年月日、個人番号、メールアドレス)を
  書かないでください。メールアドレス、電話番号、郵便番号、12 桁の数字に見える物が入って
  いると、AI に送らずに戻します
- あなたは、いつでも自分の記録を見られ、すべて消せます。消した後に作る報告書には使いません
- 答えは AI のモデルが書いた物です。間違っていることがあります。法律、税、お金のことは、
  役所の公開の資料や専門の窓口で確かめてください
