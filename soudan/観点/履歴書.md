# 履歴書

本人が書いた履歴書の下書き(識別情報を除いた物)を見ます。どういう内容にするかは本人が決めます。

- 志望動機と自己 PR が、本人の経験の具体的な事実に支えられているかを見ます
- 応募先で何をしたいかと、本人の長所がつながっているかを見ます
- 学歴・職歴の年月が、順に並び、食い違っていないかを見ます
- 和暦と西暦、数字の書き方が、1 つの書類の中でそろっているかを見ます
- 誤字、主語と述語のねじれ、意味の通りにくい文を挙げます
- 様式の欄の決まりは、使う様式に印刷してある注意で確かめるよう伝えます。aiai の rirekisho/
  にある様式(厚生労働省の様式例、JIS 様式)を使う場合は、その README の決まりを示します
