# 農業を始めるときの手続き

自分で農業を始める(独立・自営で就農する)ときの主な手続きです。
どれも役所のページで確かめ、項目ごとに出典と確かめた日を書いています。
実際に手続きをした人の報告で、足りない所を直していきます([報告のしかた](../HOUKOKU.md))。

## 手続きの一覧

| 手続き | 出す先 | 要るとき |
|---|---|---|
| 農地を借りる、買う | 農業委員会(農地法第 3 条の許可) | 農地を使うとき |
| 青年等就農計画の認定 | 市町村 | 認定新規就農者になって、支援を受けるとき |
| 就農準備資金 | 都道府県など | 就農の前に研修を受けるとき |
| 経営開始資金 | 市町村 | 認定新規就農者が経営を始めたとき |
| 開業届、青色申告承認申請書 | 税務署 | 事業として農業を始めるとき([kaigyo](../kaigyo/)) |

## 1. 農地を借りる、買う

- 農地を売り買いしたり、借りたりするときは、原則として市町村の農業委員会に申請し、
  許可を受けます(農地法第 3 条)。許可を受けていない契約は無効です
- 農地中間管理機構(農地バンク)の「農用地利用集積等促進計画」で借りる方法もあります
- オンライン(eMAFF)でも申請できます
- 以前は、取得した後の面積が一定以上であること(下限面積要件)が許可の要件でした。
  この要件は 2023 年 4 月 1 日に廃止されました。全部効率利用要件、常時従事要件、
  地域との調和要件は、今も許可の要件です

出典:

- 農林水産省「農地の権利を取得するための手続き」
  (https://www.maff.go.jp/j/keiei/koukai/pdf/tetsuzuki.pdf)
- 農林水産省「農地をめぐる事情について」
  (https://www.maff.go.jp/j/keiei/koukai/wakariyasu.html)
- 前橋市「農地法の下限面積廃止について(令和5年4月1日)」
  (https://www.city.maebashi.gunma.jp/soshiki/nogyoiinkaijimukyoku/oshirase/36018.html)

2026-09-25 に確かめました。

## 2. 青年等就農計画の認定(認定新規就農者)

- 「青年等就農計画認定申請書」を作り、市町村に出します。市町村が審査して認定します
- 対象は、青年(原則 18 歳以上 45 歳未満)、特定の知識や技能を持つ中高年(65 歳未満)、
  またはこれらの人が役員の過半数を占める法人です
- 申請の前に、都道府県の普及指導センターに相談することが勧められています
- 様式は Word のファイルで配られています。記入の見本と書き方の参考の PDF もあります
- 認定を受けると、経営開始資金、無利子の青年等就農資金などの対象になります

出典: 農林水産省「認定新規就農者制度について」
(https://www.maff.go.jp/j/new_farmer/nintei_syunou.html)。2026-09-25 に確かめました。

## 3. 就農準備資金、経営開始資金

- 就農準備資金: 道府県の農業大学校や先進的な農家などで研修を受ける 49 歳以下の人に、
  研修の間、月 13.75 万円(年に最大 165 万円)を最長 2 年交付します
- 経営開始資金: 経営を始めてから安定するまでの最大 3 年間、月 13.75 万円
  (年に 165 万円)を交付します。青年等就農計画の認定が要ります。交付するのは市町村です
- 農林水産省のページには、「申請様式の作成前に交付主体(市町村)に必ずご相談ください」と
  書いてあります

出典: 農林水産省「就農準備資金・経営開始資金」
(https://www.maff.go.jp/j/new_farmer/n_syunou/roudou.html)。2026-09-25 に確かめました。

## 4. 税務署への届出

事業として農業を始めるときは、開業届を出します。開業届の「所得の種類」では、
「事業(農業)所得」を選びます。青色申告にするときは、青色申告承認申請書も出します。
項目と見本は [kaigyo](../kaigyo/) にあります。

## 同じことを何回も書く所

農業を始めるときも、同じ事実(氏名、住所、作る物、使う農地、始める日)を、農業委員会、
市町村、税務署に書きます。見る所はそれぞれ違います。

- 農業委員会は、農地をすべて効率よく使うか、いつも農作業をするか、周りの農地の
  使い方に合うかを見ます(許可の 3 つの要件)
- 市町村は、経営の計画(青年等就農計画)を見ます
- 税務署は、所得の種類と業種を見ます

`事業.sheet.adoc` に 1 回書き、書類ごとに写す、書き分ける、本人が決める、という
[kaigyo](../kaigyo/) のやり方が、そのまま使えます。経営の計画のように長い文を書く所は、
AI が本人に聞きながら本人の言葉から下書きし、本人が直します。

## 青年等就農計画のデータを作る

農林水産省の「青年等就農計画認定申請書」(Word)と、「記入イメージ」「記載方法(参考)」を
読んで、項目の一覧を作りました。

```
python tools/todoke.py tsukuru nougyou/事業.sheet.adoc nougyou/青年等就農計画.koumoku.adoc
python tools/todoke.py uketsuke nougyou/青年等就農計画.koumoku.adoc nougyou/見本
```

| ファイル | 中身 |
|---|---|
| `事業.sheet.adoc` | 本人が書くデータの見本(架空の人です)。作目と農地の表もここに書きます |
| `青年等就農計画.koumoku.adoc` | 申請書の項目と表。名前、必須か、書き方、どこから写すか、説明(様式の備考の番号付き) |
| `見本/` | 書き終えた 1 件と、直す所のある 1 件 |

- 氏名、住所、生年月日、就農地、経営開始日、営農類型、作目と農地の表は、
  `事業.sheet.adoc` から写します
- 将来の農業経営の構想、経営管理に関する目標、農業従事の態様等に関する目標は、
  AI が本人の言葉から下書きします。記載方法には、審査の観点として
  「これまでの研修経験等を踏まえ、当該計画の生産方式に係る農業技術を習得しているか」
  とあるので、依頼にその観点を入れています
- 所得や労働時間の目標、機械、資金、働く人、研修の表は、本人が決めて書きます
- 同じ `事業.sheet.adoc` から、開業届のデータも作れます(`kaigyo/開業届.koumoku.adoc`)

国税庁の様式と違い、この様式の欄にはコードが印刷されていません。

この見本で扱っていない所: 特定作業受託、作業受託、農畜産物の加工・販売、中高年の人の
経歴と知識・技能の欄、法人や夫婦での共同申請、他の市町村での認定状況。

## まだ無いもの

- 農地法第 3 条の許可申請書の項目の一覧(`〜.koumoku.adoc`)
- 国民年金、国民健康保険、農業者年金など、勤め先を辞めて農業を始めるときの手続き
- 実際に手続きをした人の記録
