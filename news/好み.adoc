= aiai ニュースの好み
:件数: 1 日に 3 件から 5 件
:地域: 日本と海外の両方
:言葉: 日本語で書く。英語の記事も読む

この好みは、aiai のニュース(https://aiai.aiseed.dev/news/)の物です。自分のニュースを作る人は、
このファイルを写して、自分の分野と見る目に書き替えます。

== 分野

=== VLM

画像や動画を読んで言葉で答える AI のモデル。新しいモデル、手元の機械で動く物、現場
(畑、店、空き家、民泊、ジム)で使った例を先に。学習に使うデータの決まりや、利用の決まりも見る。

VLM をこれから使える場所のニュースも、この分野に入れる。いまは次の 2 つ。

- 建物の機器: カメラ、鍵、ドア、センサー。家、店、民泊、ジム、空き家で使う物。VLM の判断を
  機器につなぐ共通の規格(Matter、Aliro など)、新しい製品、不具合や漏えいの知らせ
- 鳥獣対策: シカ、イノシシ、サル、カラス、クマなどが、畑や建物に入らないようにすること。捕獲よりも、
  入らせないこと(柵、音、光、カメラで見つけて知らせる)を中心に。動物と一緒に暮らす工夫も

== まず見る所

検索の前に、分野ごとに次を見ます。どれも、新しい物を知るための入り口です。記事にするときは、元の出どころ(会社の
発表、モデルの説明のページ、論文、役所の資料)まで辿り、元を出典にします。2026-10-16 に、どれも開けることを
確かめました。

=== VLM

- Roboflow のブログ(https://roboflow.com/blog): 新しい VLM を現場の使い方で比べ、製造の検査などでの使い方を書く。
  比べは、この会社が自分で決めた基準の物なので、使うときはそう書く
- Hugging Face の Daily Papers(https://huggingface.co/papers): その日に注目された論文の一覧
- arXiv の画像の分野の新着(https://arxiv.org/list/cs.CV/new)
- Simon Willison のブログの VLM の記事(https://simonwillison.net/tags/vision-llms/): 新しい VLM を自分で試した
  記録。手元の PC で動かした結果も書く
- OCRBench v2(https://99franklin.github.io/ocrbench_v2/): 画像の中の文字を読む力の比べ
- Hugging Face の新しいモデルの説明のページと、モデルの作り手の公式の発表

=== 建物の機器

- CSA(Matter と Aliro を決める団体)のニュースの一覧(https://csa-iot.org/newsroom/): 団体の発表と、団体が
  紹介する記事。Cloudflare の確かめの画面で開けない日は、ブラウザーで開くか、紹介されている元の記事
  (9to5Mac、HomeKit News など)から辿る
- JVN(https://jvn.jp/): 日本の製品の弱点の知らせ
- IPA の重要なセキュリティ情報(https://www.ipa.go.jp/security/security-alert/)
- 米国 CISA の、実際に悪用された弱点の一覧(https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
- 個人情報保護委員会(https://www.ppc.go.jp/): 識別情報の扱いの決まりの変更、漏えいの知らせ

=== 鳥獣対策

- 環境省「クマに関する各種情報・取組」(https://www.env.go.jp/nature/choju/effort/effort12/effort12.html):
  出没の数、人身被害の数、対策
- 農林水産省「鳥獣被害対策コーナー」(https://www.maff.go.jp/j/seisan/tyozyu/higai/)
- 県や市町村の発表と、地元の新聞

=== 使い方の決まり

- Yahoo!ニュースのように、ほかの新聞社の記事を集めて載せる所は、元の新聞社の記事まで辿り、元の記事を出典にする
- 会社の発表(PR TIMES など)は使ってよい。ただし、中身の分からない宣伝だけの物は使わない

== 扱わない物

- 伝統食品
- 宣伝だけの記事(新しい品物の知らせだけで、中身の分からない物)

== 落とさない物

- カメラや鍵は、使う人の識別情報(顔、出入りの記録など)を扱う。識別情報の扱いに関わる
  ニュース(漏えい、決まりの変更など)
