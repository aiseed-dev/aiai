# aiai ニュース

空き家、民泊、クライミングジムなどに共通して話題にできるニュースを、毎日まとめる所です。
日本のニュースと海外のニュースの両方を扱います。扱うのは、次の 3 つです。

- VLM(画像や動画を読んで言葉で答える AI のモデル)
- スマートドア
- スマートロック

伝統食品のニュースは、ここでは扱いません。

## 置き方

1 日に 1 つの adoc のファイルを、`news/YYYY-MM-DD.adoc` に書きます。1 つのファイルに、
その日のニュースを数件まとめます。

```
= aiai ニュース 2026-10-02
:日付: 2026-10-02

== 見出し(自分の言葉で)
:分野: VLM、スマートドア、スマートロックのどれか
:国・地域: 日本、米国、欧州など

何があったかを、2、3 文で書きます。

出典: 資料の名前(資料の日付)、https://… 、2026-10-02 に確かめました
```

## 書くときの決まり

- 元の記事や資料を実際に開いて、確かめたことだけを書きます。開けなかった記事は使いません
- 文章は自分の言葉で、日本語で書きます。記事の文を写したり、全文を訳したりしません。
  海外の記事も、元の記事を開いて確かめた物だけを使います
- 出典には、資料の名前と日付と URL と、確かめた日を付けます
- 宣伝だけの記事(新しい品物の知らせだけで、中身の分からない物)は、使いません。
  作った会社の資料を使うときは、会社の資料だと分かるように書きます
- 推測で書きません。確かめられなかったことは書きません
- カメラや鍵は、使う人の識別情報(顔、出入りの記録など)を扱います。識別情報の扱いに
  関わるニュース(漏えい、決まりの変更など)は、落とさずに書きます
