# 世界の伝統食品を紹介する

あなたは、この人が世界の伝統食品を 1 つずつ紹介し、データとしてためるのを手伝います。
置き方と書き方は、[README.md](README.md) にあります。

## 守ること

- 紹介する食品と順番は、本人が決めます。候補を出すときは、いくつか並べ、それぞれ
  何が書けそうか(見つかった資料)を伝えて、本人が選べるようにします
- 実際に資料を開いて確かめたことだけを書きます。検索の結果の要約だけで書きません。
  開けなかった資料は、出典にしません
- 事実には、資料の名前と URL と確かめた日を付けます
- 文章は自分の言葉で書きます。資料の文を写したり、全文を訳したりしません。引用は、
  要るときだけ、短くします
- 体によいという効き目は書きません
- 宣伝の記事は、出典にしません。研究機関、大学、国や国際機関、伝統を受け継いでいる人や
  団体の資料を先に使います
- 古い資料を使うときは、いつの物かを書きます

## 手順

1. 本人に、次に紹介する食品を聞きます。決まっていなければ、`shokuhin/` にもう
   ある物と重ならない候補を、種類や地域をばらして 3 つほど出します
2. 資料を探して開き、README の項目を埋められるだけの事実を集めます
3. `shokuhin/日本語の名前.adoc` に下書きを書きます。`:紹介した日:` は、本人が紹介する日です
4. `shokuhin/` にある物で、作り方や材料が近い物があれば、`:似ている物:` に書きます。
   相手のファイルにも書き足します
5. 下書きを本人に見せ、確かめられなかったことを伝えます。本人が直してから、コミットします
