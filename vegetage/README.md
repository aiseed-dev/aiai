# 世界の伝統食品(vegetage)

世界の伝統食品を 1 つずつ紹介し、紹介した物をデータとしてためる所です。
ある程度たまったら、vegetage のリポジトリに移します。vegetage のリポジトリは、まだありません。
それまでの仮の置き場所として、aiai の中に置いています。

aiai のほかのフォルダーは、様式とスキルだけを置き、書く中身は置きません。このフォルダーは、
その例外です。ここに置くのは、架空の見本ではなく、資料で確かめた実際の食品のことです。

AI に [SKILL.md](SKILL.md) を読ませると、AI が資料を探して確かめ、1 つの食品の下書きを作ります。

## 置き方

1 つの食品を、`shokuhin/` の中の 1 つの adoc のファイルに書きます。ファイルの名前は、
食品の日本語の名前にします(例: `shokuhin/ザワークラウト.adoc`)。移すときは、
フォルダーごと写します。

```
= 日本語の名前
:現地の名前: その土地の言葉での名前
:国・地域: 国や地域(いくつかあれば「・」で区切ります)
:種類: 発酵、保存、行事食、穀物、豆など
:主な材料: 材料(いくつかあれば「・」で区切ります)
:似ている物: ほかの食品のファイルの名前(無ければ書きません)
:紹介した日: 2026-10-01

どんな食べ物かを、2、3 文で書きます。

== 作り方の要点

== 歴史と受け継いでいる人

== 出典

* 資料の名前、https://… 、2026-10-01 に確かめました
```

`:種類:` と `:国・地域:` と `:主な材料:` をそろえて書くと、後で、種類ごと、国ごと、
材料ごとの一覧をコードで作れます。`:似ている物:` で、食品どうしをつなぎます。

## 書くときの決まり

- 事実には、出典(資料の名前と URL)と確かめた日を付けます。`python tools/kakunin.py` で、
  確かめ直す物を一覧にできます
- 文章は自分の言葉で書きます。記事や本の文を写したり、全文を訳したりしません
- 体によいという効き目は書きません
- 宣伝の記事(新しい品物の知らせ、市場の規模の予測など)は、出典にしません
- 確かめられなかったことは書きません
- 紹介する順番と、紹介する食品は、本人が決めます
