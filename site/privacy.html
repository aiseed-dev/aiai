このサイトについて

プライバシーポリシー

このサイト(aiai.aiseed.dev)と、アプリの「作る」で、何を預かり、何に使い、いつ消すかを書きます。

1. ページの読まれ方の記録

サイトをよくするために、ページがどう読まれたかを、このサイトのサーバーに記録します。Cookie は置かず、ブラウザーに ID も置きません。IP アドレスは、この記録に入れません。

記録する物開いたページと題、来た元のサイトの名前、広告の印(utm_*)、言語、時間帯、画面の大きさ、ブラウザーと機器の種類、ページを見ていた秒数、どこまで読んだか、サイトの中で探した言葉
使い方読まれ方をまとめ、サイトを直すために使います。広告には使いません。毎日、まとめた数を Gemini に読ませ、直す所を選ばせます。直したことは、直した記録に公開します
置く期間期限は決めていません

2. サーバーの受け付けの記録

サーバーは、受けた要求ごとに、IP アドレス、日時、開いた URL、ブラウザーの種類を記録します。1 の記録の送り先は、ここに書きません。

使い方サーバーへの攻撃を数え、守るためだけに使います。毎日、穴を探す要求の数と、多かった IP アドレス 5 つまでを記録にし、Gemini に読ませて所見を書かせます。この記録は公開しません
置く期間20 MB ごとに分け、新しい 5 つまでを置き、古い物から消します

3. アプリの「作る」

登録ID と、パスワードから計算した値だけを預かります。パスワードそのものと、メールアドレスは預かりません。消してほしいときは、7 の窓口に ID を書いて知らせてください
サインインサインインの番号から計算した値を、30 日まで預かります
使った回数1 日の上限を守るため、日ごとに、何を何回使ったかを数えます
頼んだ仕事渡した資料、書いた文、できた結果を、7 日置いて消します。読めるのは、頼んだ本人だけです
対話とニュース対話の中身と、ニュースの好みは、サーバーに置きません。Gemini に送るだけです

個人番号など、誰のことか分かる情報は、書いたり資料に入れたりしないでください。

4. Gemini に送る物

アプリの「作る」で書いた文と渡した資料、サイトの中で探した言葉は、Google Cloud の Vertex AI の Gemini に送ります。Google は、次のように説明しています。

  • 事前の許可や指示なしに、送ったデータで AI のモデルを学習させない
  • Google 検索で調べる仕事では、検索に使った言葉などを、最大 3 日記録する
  • 使い方の決まりに反する使い方を見つけるため、頼みの文を記録することがある

(出典: Google Cloud「Gemini Enterprise Agent Platform and zero data retention」、https://docs.cloud.google.com/vertex-ai/generative-ai/docs/data-governance 、2026-10-15 に確かめました)

5. ブラウザーに置く物

ニュースのページで選んだ分野は、そのブラウザーの中にだけ置き、サーバーには送りません。アプリの「作る」のサインインは、アプリを開いている間だけ覚えます。

6. ほかに渡すこと

4 の Google Cloud のほかには、渡しません。売ったり、広告に使ったりしません。法令で求められたときは、その求めに従います。

7. 窓口

聞きたいこと、登録を消してほしいときは、GitHub の aiseed-dev/aiai の Issues に書いてください。Issues は公開なので、誰のことか分かる情報は書かないでください。
