= スキルの一覧
:メニュー: スキル
:順番: 1

どのスキルも、あなたの AI に読ませて使います。

== 考える

|===
|転職を考える |これまでのチャットから自分の長所を AI に探してもらい、ソフトウェアの外の仕事に活かす道を考え、AI でアプリを作る体験をして、次の行動を決めます。自分で自分の長所を探す仕組みなので、仕事を紹介する転職エージェントとは、役割が違います
|AI の時代、何を学ぶか |高校生と大学の 1 回生向けです。チャットから自分の長所を探し、AI でアプリを作る体験をして、何を学び、何をするかを決めます
|===

== 作る

|===
|現場で VLM を使う |現場で撮った写真を VLM(画像を読む AI)に見せて、仕事の判断を助ける小さなアプリを作ります。何を見るかはあなたが決め、AI の答えは人が確かめて記録します
|履歴書 |厚生労働省の様式例と JIS 様式。どういう内容を書くかは、あなたとあなたの AI に任せます
|開業届と青色申告承認申請書 |国税庁の様式と照らし合わせた項目と、データの見本
|農業を始める |就農の手続きと、青年等就農計画の項目。自然農法の経営計画を作るスキル
|事業の Web サイト |公開してよい事実だけを写して、静的なページを作ります
|申し込み |Apple ID か Google ID でサインインした人から、取り置き、予約、注文を受ける仕組み
|===

見本の人、店、数字は、すべて架空です。
