# 開業届と青色申告承認申請書

自分の事業のことを 1 つのファイルに書き、そこから税務署に出す 2 つの書類の
データを作る見本です。書類は docx や xlsx ではなく、adoc の文字のファイルで
やり取りします。

## 流れ

1. 本人が、自分の言葉で `事業.sheet.adoc` を書きます
2. `tools/todoke.py tsukuru` が、書類ごとのデータを作ります。同じ内容
   (氏名、住所、屋号など)は、ここで写します
3. 書類ごとに本人が決める項目と、書類の目的に合わせて書く文が残ります。
   `〜.依頼.md` を AI に渡すと、AI は答えを出さずに、何のための項目か、
   選ぶと何が変わるかを役所の書き方の範囲で伝え、本人に 1 つずつ聞きます。
   文は本人の言葉から下書きを書き、本人が直します。考えて決めるのは本人です
4. 受け取る側は、`tools/todoke.py uketsuke` で、届いた adoc をまとめて
   確かめ、一覧にします

```
python tools/todoke.py tsukuru kaigyo/事業.sheet.adoc kaigyo/開業届.koumoku.adoc
python tools/todoke.py tsukuru kaigyo/事業.sheet.adoc kaigyo/青色申告.koumoku.adoc
python tools/todoke.py uketsuke kaigyo/開業届.koumoku.adoc kaigyo/見本
```

AI への依頼には、「本人」の表(氏名、住所、電話)と個人番号を入れません。
入れるのは「事業」の表だけです。

## ファイル

| ファイル | 中身 |
|---|---|
| `事業.sheet.adoc` | 本人が書くデータの見本(架空の人です) |
| `開業届.koumoku.adoc` | 開業届の項目。名前、必須か、書き方、`事業.sheet.adoc` のどこから写すか、説明 |
| `青色申告.koumoku.adoc` | 青色申告承認申請書の項目 |
| `見本/` | 受け取る側の見本。書き終えた 2 件と、直す所のある 1 件 |

見本の個人番号は、0 を 12 個並べた物です。最後の 1 桁の検査を通るようにだけ
してあります。

## adoc でやり取りする理由

- 人が読めます。テキストエディターでも、GitHub の画面でも表になります
- 機械も読めます。`tools/todoke.py` は Python の標準ライブラリだけで書いて
  あります。受け取る側に、表計算やワープロのソフトは要りません
- 中身と見た目を分けられます。印刷する見た目は、様式の側が受け持ちます。
  docx や xlsx の見た目を合わせる作業が要りません

役所や専門家は仕事を分けて受け持っているので、同じ氏名や住所を、書類ごとに
何回も書きます。同じ事実でも、受け取る所によって見る所が違います。写す所は
コードで、見る所に合わせて書く所は AI の手伝いで、決める所は本人が受け持ちます。
このやり方は、企業の中の申請でも使えます。

## 2 つの様式を並べて分かったこと

- 2 つの様式は、同じ欄に同じコードを印刷しています。提出先 F01、フリガナ F03、
  氏名 F04、納税地の郵便番号 F05、納税地 F06、電話番号 F07、生年月日 K01、
  職業 K02、屋号のフリガナ K03、屋号 K04 です
- 納税地以外の住所の欄は、コードが違います。開業届は P01(郵便番号)と
  E01(住所地等)、青色申告承認申請書は F32(郵便番号)、F33(住所地等)、
  F35(電話番号)です
- 納税地の区分は、開業届では K05 ですが、青色申告承認申請書の欄には
  コードがありません
- 所得の種類の選ぶ言葉が違います。開業届は「事業(農業)所得」、青色申告
  承認申請書は「事業所得」です。この見本では、開業届の所得の種類を本人が
  選ぶ項目にしています
- 国税庁の PDF には入力の欄があります(開業届は 79、青色申告承認申請書は 47)。
  欄の名前は「テキスト1」「Check Box63」のような通し番号で、上のコードは
  付いていません

## まだ無いもの

- 印刷。国税庁の様式に合わせて PDF にするには、コードと PDF の入力の欄を
  結び付ける表が要ります
- 開業届の廃業の欄、給与等の支払の状況、税理士の欄
- 提出の期限の検査(青色申告承認申請書は、1 月 16 日以後の開業なら開業日から
  2 か月以内。書き方 2)
