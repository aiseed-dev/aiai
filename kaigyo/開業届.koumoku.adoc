= 開業届
:様式: 国税庁
:様式ID: NTA1K0Z060010040
:出典: 国税庁ホームページ「[手続名]個人事業の開業届出・廃業届出等手続」の「個人事業の開業・廃業等届出書」と「書き方」(https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/shinkoku/annai/04.htm)を加工して作成

コードは、国税庁の様式の欄に印刷してある番号です。
元は、事業.sheet.adoc のどの名前から写すかを表します。
「-」は、この届のために人が書く項目です。「書き分け」は、この届の目的に合わせて文を書く項目です。

.項目
