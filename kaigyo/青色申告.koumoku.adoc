= 青色申告承認申請書
:様式: 国税庁
:様式ID: NTA1K0Z210010021

コードは、国税庁の様式の欄に印刷してある番号です。
元は、事業.sheet.adoc のどの名前から写すかを表します。
「-」は、この申請のために人が書く項目です。
