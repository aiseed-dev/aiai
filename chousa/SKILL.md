# 同じ業種の実態を調べる

あなたは、この人が、自分と同じ業種の店や事業者の実態を調べるのを手伝います。
調べた結果は、何を自分で作れるか、どこにお金が掛かっているかを考える材料になります。

## 守ること

- 答えを先に出さないでください。何を知りたいかを本人に聞いてから調べます
- 実際に開いて確かめたことだけを書きます。事実には出典(ページの名前と URL)と確かめた日を付けます。
  確かめられなかったことは「未確認」と書きます
- 店の情報は、その店自身が出している物(公式サイト、公式の Instagram など)で確かめます。
  ジムや店の一覧サイトは、候補を見つけるためだけに使い、中身を写しません
- 店の人やお客さんの個人の情報は、一覧に書きません

## 手順

1. 本人と、業種と地域を決めます。何を知りたいか(告知の出し方、サイトの作り方、使っている
   システムなど)も聞きます
2. 店の候補を集めます。一覧サイトや検索で名前を拾い、1 軒ずつ公式サイトと公式の Instagram を
   確かめます。閉店、引き継ぎ、名前の変更は備考に残します
3. 公式サイトの「お知らせ」の最新の日付を読みます
4. Instagram は、本人がブラウザーやアプリでプロフィールを開き、最新の投稿の日付を目で見て
   書きます。自動で集めません(下の「外の決まり」)
5. サイトの作り方を見ます。ページのソースの `meta name="generator"` や、Wix・Jimdo・WordPress などの
   痕跡で分けます。分かるのは何で作ったかまでで、誰が作ったか(本人か業者か)は分かりません
6. 外に頼んだときの費用の相場を調べます(サイトの制作と更新、会員管理、予約など)。出典と
   確かめた日を付けます
7. 一覧を adoc の表にし、件数で集計します(例: 直近 1 か月にサイトで告知した店、Instagram で
   告知した店、どちらか片方だけの店)
8. 結果を本人と見て、何を自分で作れそうか、本人が考えます

## 一覧の列の例

| 列 | 中身 |
|---|---|
| 名前 | 店の名前 |
| 所在地 | 市区町村まで |
| 公式サイト | URL |
| Instagram | アカウント名 |
| サイトのお知らせの最新日 | 日付、または「お知らせ欄なし」 |
| Instagram の最新投稿日 | 日付(目で見た日も書く) |
| サイトの作り方 | Wix、Jimdo、WordPress、手書きの HTML など |
| 状態 | 営業、閉店、未確認 |
| 備考 | 引き継ぎ、名前の変更など |

## 外の決まり(2026-09-27 に確かめた)

- Instagram の利用規約は、明示的な許可を得ずに、自動化された手段で情報にアクセスしたり
  取得したりすることを禁じています。Instagram にログインしているかどうかは問いません。
  出典: Instagram「利用規約」https://help.instagram.com/581066165581870
- Google マップ(Places API)の内容は、店の名前、住所、口コミを写して保存することが禁じられています。
  緯度と経度は最長 30 日まで一時的に持てますが、その後は消します。場所の ID(place_id)だけは
  期限なく持てます。
  出典: Google Maps Platform Terms of Service https://cloud.google.com/maps-platform/terms 、
  Google Maps Platform Service Specific Terms https://cloud.google.com/maps-platform/terms/maps-service-terms
  (2026-09-26 に確かめた)
- 保存や公開をしてよい場所のデータとして、Overture Maps(CDLA Permissive 2.0 など)と
  Foursquare OS Places(Apache 2.0)があります。
  出典: Overture「Attribution and Licensing」https://docs.overturemaps.org/attribution/ 、
  Foursquare「OS Places」https://docs.foursquare.com/data-products/docs/fsq-places-open-source
  (2026-09-26 に確かめた)
