# 履歴書

| ファイル | 中身 |
|---|---|
| `履歴書-厚労省.form.adoc`、`.tmpl.adoc` | 厚生労働省の「履歴書様式例」の様式と見た目 |
| `履歴書-JIS.form.adoc`、`.tmpl.adoc` | JIS 様式の様式と見た目。性別、通勤時間、扶養家族数、配偶者、配偶者の扶養義務の欄があります |
| `履歴書.sheet.adoc` | 見本のデータ(架空の人です) |
| `photo.jpg` | 見本の写真(図形で描いた物です) |
| `make_forms.py` | 厚生労働省の履歴書様式例の xlsx から、2 つの様式を作り直すスクリプト |

## 埋める

```python
from officework import sheet

様式 = sheet.Book.open("履歴書-厚労省.form.adoc")   # JIS 様式なら 履歴書-JIS.form.adoc
データ = sheet.Book.open("履歴書.sheet.adoc")
b = sheet.Book.fill(様式, データ)
b.save("履歴書.pdf")
```

自分の履歴書を作るときは、`履歴書.sheet.adoc` を写して、自分の値に書き換えます。
「基本」の表の写真には、写真のファイルの名前を書きます(データのファイルと同じ
フォルダーに置きます)。学歴・職歴の行が様式に入りきらないときは、残りの行が
別紙に続きます。

JIS 様式だけにある欄(通勤時間、扶養家族数、配偶者、配偶者の扶養義務)は、
「基本」の表に行を足して書きます。通勤時間は `1時間10分` の形で書きます。

## 様式を作り直す

```
python make_forms.py 03_a4.xlsx
```

`03_a4.xlsx` は、厚生労働省「公正な採用選考をめざして」の「採用選考の具体的な方法」の
ページにある A4 版の Excel(`03_a4.xls`)を、xlsx にして保存した物です。書体を BIZ UD にし、
行の高さを A4 の 1 ページに収め、値を入れるセルに印を置きます。officework が要ります。

## 出典

出典:厚生労働省ホームページ「公正な採用選考をめざして」採用選考の具体的な方法、
履歴書様式例 A4 版(Excel)(https://kouseisaiyou.mhlw.go.jp/methods.html)を加工して作成。
書体、行の高さ、値を入れるセルの印を変えています。このページは、厚生労働省の「利用規約・著作権」
(https://www.mhlw.go.jp/chosakuken/index.html)にリンクしていて、公共データ利用規約(第 1.0 版)で
使えます。2026-09-26 に確かめました。

同じ様式例は、ハローワークインターネットサービスでも配られています
(https://www.hellowork.mhlw.go.jp/doc/kouroushourirekishoA4.xls)。いまの 2 つの様式は、
このファイルから作りました。2 つのファイルの中の文言(275 か所)が同じことは確かめてあります。
作り直すときは、公共データ利用規約で配られている `03_a4.xls` の方を元にします。

JIS 様式の欄と記入上の注意は、厚生労働省「新たな履歴書の様式例の作成について」3 ページの
「従来の履歴書様式例(JIS 規格の履歴書様式例)」に合わせました。
