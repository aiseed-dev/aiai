# 履歴書・申請書版

officework のリボンを、履歴書と申請書を書くための物にします。
リボンの設定ファイル(`ribbon.toml`)と、Python のボタン 3 つです。

```
python office/install.py            # 置く
python office/install.py --remove   # 取り除く(元のリボンに戻る)
```

置いた後に officework を起動し直すと、ウィンドウのタイトルが
「aiseed office 簡易版」になり、タブは ファイル、書類、ホーム、挿入、レイアウト、共同編集、
表示、確かめる、報告 になります。ホームから表示までは、AI が作った計画書や申請書を、
adoc、docx、xlsx のまま人が直すためのタブです。ほかのタブとボタンは、消さずに隠します。
隠したボタンも、マクロの `xw.press` からは押せます。

| タブ | ボタン | すること |
|---|---|---|
| 書類 | 保存、印刷 | officework のボタンです |
| ホーム、挿入、レイアウト、共同編集、表示 | officework のボタン | 書類を直すためのボタンです |
| 書類 | 様式で埋める | 開いているデータ(`.sheet.adoc`)で様式を埋め、PDF をデータの隣に書きます |
| 確かめる | 足りない名前と別紙 | データに無い名前と、別紙に続く表をステータス バーに出します。ファイルは書きません |
| 報告 | 報告の下書き | データの値を含まない報告の下書きを、データの隣の `報告の下書き.txt` に書きます |

様式は、データの 1 行目の書類の名前と `:様式:` から探します。`= 履歴書` と
`:様式: 厚労省` なら `履歴書-厚労省.form.adoc` です。データと同じフォルダーを
先に探し、無ければ aiai の中を探します。

ボタンは、データを保存してから押してください。保存していない変更があると断ります。

macOS で確かめました。Linux と Windows ではまだ確かめていません。
編集のタブ(ホームから表示まで)を足した並びは、macOS の officework の表の画面で、
`履歴書.sheet.adoc` を開いて確かめました。タイトルが「aiseed office 簡易版」になり、
タブが ファイル、書類、ホーム、挿入、レイアウト、共同編集、表示、確かめる、報告 の順に出て、
書類タブに 保存、印刷、様式で埋める が並びました(2026-09-26)。文書の画面では、
まだ確かめていません。

## officework との関係

officework は、aiai とは別のプロジェクトです。aiai は、公開されている officework を
使う側で、ここに置くのは、リボンの設定ファイルと Python のボタンだけの簡易版です。
専用のアプリは作りません。機能が足りないときや、バグを見つけたときは、officework の
Issues(https://github.com/aiseed-dev/officework/issues)に報告します。
